# Homestead Media (wcyt.org/media)

Static site served from the GitHub repo `dunnand/media`, branch `master`. Pushing to `master` publishes the site. See `REFERENCE.md` for site details.

## Workflow (this repo is edited from more than one computer)

1. **At the start of every session, run `git pull` before making any changes.** Another computer may have pushed updates. If the pull fails or conflicts, stop and tell the user.
2. **After finishing each change, commit and push immediately** without asking first. Do not leave work uncommitted or unpushed, because the other computer will not see it.
3. Keep commit messages short and descriptive of the change, as in the existing history.
4. Do not commit the local `.claude/` folder.
